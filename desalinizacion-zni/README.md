# Digital Twin — Desalinización ZNI

Proyecto académico de Ingeniería de Sistemas, UNAD, grupo 58.

La carpeta `desalinizacion-zni/` alojará el prototipo autocontenido de alta fidelidad (`index.html`). Los datos de operación son virtuales y no corresponden a mediciones físicas ni a validación experimental.

## Publicación

1. Abrir esta carpeta en GitHub.
2. Seleccionar **Add file → Upload files** y cargar el archivo `index.html` del paquete `ZNI_F4_Publicacion_GitHub_Pages.zip`.
3. Confirmar el commit en la rama `master`, sin sobrescribir otros archivos.
4. En **Settings → Pages**, seleccionar **Deploy from a branch**, rama `master` y carpeta `/(root)`.
5. Verificar que esté disponible `https://enriquevillap.github.io/desalinizacion-zni/` y tomar capturas de la URL real.
6. Comprobar navegación, escenarios, planta integral, historial y descarga CSV/JSON desde otro navegador.
